# 认知适应中间表示

## 1. 为什么需要 IR

微调把经验压缩进权重，Prompt 把要求临时放入上下文，Memory 保存历史事实。三者都能改变 Agent 行为，但缺少一个统一层来回答：

- 这次行为变化具体代表什么 cognition；
- 它适用于哪些场景；
- 它如何被修改、验证和回滚；
- 它能否换模型继续使用；
- 它与另一个 cognition 为什么冲突；
- 它是否有权被共享和交易。

INA 的核心假设是：在经验和行为之间，可以存在一层独立的认知表示。

```text
Experience
    ↓
INA-seq
    ↓
Cognitive Adaptation IR
    ↓
Prompt / Runtime / Training
    ↓
Agent Behavior
```

## 2. 核心三角

```text
                 Representation
                /              \
               /                \
      Extraction -------------- Execution
```

### Extraction

从可观测行为中识别稳定的认知变化。

### Representation

以模型无关的方式表达作用域、策略、示范、偏好、证据和演化。

### Execution

把 cognition 转换为能改变具体 Agent 行为的形式。

任何一角失败，INA 的完整主张都无法成立。

## 3. Cognitive Delta

INA 不表示完整智能，而表示相对基准的认知增量：

```text
C_target = C_base + ΔC_INA
```

多个适配器可以写为：

```text
C_agent =
C_base
+ ΔC_core
+ ΔC_domain
+ ΔC_team
+ ΔC_user
```

这里的加号不是简单拼接，而代表经过路由、优先级和冲突解析后的组合。

## 4. 三种表示状态

### Symbolic State

作为源代码存在，适合编辑、审计、交易和 Graft。

### Compiled State

针对某个 Runtime 或模型优化，适合快速执行。

### Neural State

以内化的参数增量存在，适合高频、低延迟或稳定 cognition。

同一 INA 的不同状态必须通过统一标识和谱系关联。

## 5. 语义不变量

无论编译到哪种 Backend，以下语义应尽量保持：

- 适用范围；
- 核心偏好；
- 认识论约束；
- 禁止和升级条件；
- 失败边界；
- 置信度策略；
- 可被什么证据修正。

如果编译产物丢失这些信息，需要记录 Compilation Loss。

## 6. Compilation Fidelity

用于衡量编译后行为是否仍忠实于 Symbolic INA。

建议分为：

- **Policy Fidelity**：核心策略是否保持；
- **Scope Fidelity**：是否只在适用情境激活；
- **Epistemic Fidelity**：证据、反证和不确定性纪律是否保持；
- **Failure Fidelity**：是否仍能识别原定义的失败边界；
- **Edit Fidelity**：修改源 INA 后，编译产物是否产生预期变化。

## 7. 为什么不是完整符号主义

INA 不试图把所有推理步骤写成规则。

保留给基础模型的能力包括：

- 模糊语义理解；
- 类比和创造；
- 长尾上下文处理；
- 自然语言生成；
- 不完全信息下的柔性推理。

INA 只显式化那些值得控制、迁移、评测、组合和交易的认知结构。

## 8. IR 成立的最低证明

1. 同一 Symbolic INA 可编译到至少两个 Backend；
2. 两个 Backend 的行为都保留核心语义；
3. 修改 Symbolic INA 能导致可预测的行为变化；
4. 这种显式层带来至少一项直接方案难以获得的价值。
