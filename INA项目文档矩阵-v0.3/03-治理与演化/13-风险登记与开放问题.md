# 风险登记与开放问题

## 1. 概念风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| Cognition 定义无限扩张 | 项目不可测 | 限定可观察行为与作用域 |
| 把世界观做成意识形态 | 工程和伦理失控 | 拆成认识论、方法论、偏好 |
| 把风格当认知 | 虚假迁移 | 评价决策和行动，不评价语气 |
| “认知基因”叙事过度 | 可信度下降 | 使用 Cognitive Delta 的严格表述 |

## 2. 科学风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| 提取器事后解释 | 虚假规则 | 重复提取、隐藏集、反例 |
| 数据泄漏 | 夸大效果 | 冻结测试集和来源隔离 |
| 裁判模型偏好 | 评价失真 | 人工盲评、多裁判 |
| 只和弱基线比较 | 无法证明价值 | Prompt、Checklist、Training 强基线 |
| 反谄媚变成反对癖 | 能力下降 | 同时测准确率和反对率 |

## 3. 工程风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| Schema 过重 | 无法采用 | 最小必填与扩展字段 |
| 所有 INA 全量注入 | Context 污染 | Router 与激活阈值 |
| Runtime 绑定单模型 | 无法迁移 | 模型适配层 |
| 编译丢失语义 | Neural INA 不可信 | Compilation Fidelity |
| 演化回归 | 历史能力丢失 | Replay、Regression、Rollback |

## 4. 治理风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| 原始对话被当商品 | 隐私与法律问题 | 只交易脱敏认知资产 |
| 来源不清 | 无法授权 | Provenance 与许可必填 |
| 低质量 INA 传播 | 谱系污染 | 验证等级和撤销 |
| 企业认知泄露 | 商业秘密风险 | 私有 Registry 和端侧部署 |
| 核心宪法被用户修改 | 安全与可靠性下降 | 分层权限和高门槛变更 |

## 5. 商业风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| 用户只需要 Prompt | 无付费理由 | 证明迁移、编辑、审计增益 |
| 免费额度太少 | 用户未体验价值 | 覆盖最小成长闭环 |
| 免费额度太多 | 成本失控 | 基于调用成本和转化调整 N |
| 市场先于资产标准 | 劣币驱逐良币 | 先做 Schema、验证和许可 |
| 企业普通策略系统已足够 | INA 无差异化 | 用长期演化和跨模型迁移验证 |

## 6. 关键开放问题

1. INA 的最小认知单元是什么？
2. 何种行为稳定性才算 cognition？
3. Symbolic INA 与高质量 Prompt 的最低差异是什么？
4. 如何量化 Cognitive Distance？
5. 如何进行跨 Backend 语义对齐？
6. Router 的输入和训练方式是什么？
7. 核心宪法是否允许个性化？
8. 如何分配失败责任？
9. Graft 的冲突解决权来自哪里？
10. Neural INA 如何回译或审计？
11. 认知资产的著作权、商业秘密和衍生权如何界定？
12. 免费层需要多少次 Agent 调用才能达到首次价值？
13. 企业端侧是否愿意接受 Compiled INA 的更新和撤销机制？
14. 当核心假设失败时，项目应收缩成 Runtime Policy、Dataset Compiler 还是 Evaluation Infrastructure？

## 7. 项目级 Kill Criteria

以下任一结论被多轮实验稳定支持时，应重新评估 INA 主线：

- 不存在可稳定提取的认知适应；
- INA 只等价于更长 Prompt；
- 直接训练在效果和治理上都全面优于 INA；
- 显式 cognition 无法跨模型；
- 进化和组合不可控；
- 认知资产没有复用和付费价值。
