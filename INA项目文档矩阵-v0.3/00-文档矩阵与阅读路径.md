# INA 文档矩阵与阅读路径

## 1. 这套文档解决什么问题

本目录是 INA 项目的第一笔正式文档基线。它不再使用一份超长报告承载全部内容，而是把项目拆成可独立维护、互相引用、能够随研究进展持续演化的文档矩阵。

当前文档聚焦四件事：

1. 明确 INA 的技术本体与边界；
2. 把核心主张改写成可证伪研究问题；
3. 建立可进入工程实现的架构、协议和评测基线；
4. 保留可交易性、企业端侧部署和按 Agent 调用次数计费的长期商业方向。

本阶段不重点编写界面、交互流程、页面原型和完整 PRD。产品设计应在核心认知效应得到初步验证后单独立项。

## 2. 来源基线

这套文档综合以下输入：

- `INA_Project_Definition.pdf`：最初的认知基因、决策模式、偏好、进化、谱系、嫁接和市场愿景；
- `Reusable Deep-Research Plan and Report Template.pdf`：研究章程、Claim Register、证据分级、反证、替代解释和修正触发器；
- 2026-08-13 项目讨论：认识论独立、反谄媚、因果方向、认知免疫、Fine-tuning 与 INA 的关系、Cognitive Adapter、Cognitive Delta、Symbolic/Compiled/Neural INA；
- 最新商业约束：免费额度按照 Agent 调用次数计算，可交易性保留，企业端侧 Agent 是重要长期场景。

## 6. 文档权威层级

发生冲突时，按以下顺序处理：

1. 已通过实验和评审的 ADR；
2. 当前版本的项目总纲与研究章程；
3. 当前 Schema 与评测规范；
4. 路线图和商业假设；
5. 早期愿景材料和讨论记录。

任何宏大叙事都不能覆盖负面实验结果。

## 7. 当前项目主基调

> INA 不是一个简单的、等待用户教育的结构化经验库，而是一种随着用户、Agent 与环境交互持续形成和修正的认知架构。

更严格的技术表达是：

> INA 是 Cognitive Adaptation 的中间表示：它把经验引发的认知变化显式化为可编辑、可评测、可迁移、可组合和可编译的 Cognitive Adapter。

其核心循环为：

```text
经验
  ↓
提取
  ↓
表示
  ↓
编译或执行
  ↓
行为
  ↓
评测与归因
  ↓
安全进化
```

## 8. 本阶段明确不做

- 完整产品 PRD；
- UI、设计系统和页面原型；
- 复杂计费后台；
- 大规模公开市场；
- 无人工门禁的自动进化；
- “复制完整人格”或“无损复制专家智能”的宣传；
- 在核心效应未验证前构建重型商业平台。
