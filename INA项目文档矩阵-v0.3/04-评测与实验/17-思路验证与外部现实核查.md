# 思路验证与外部现实核查

## 1. 目的与方法

本卷验证 INA（认知 DNA）思路本身的**合理性与有效性**——**不做开发，只做判断**（2026-08-05）。

证据线：

1. 内部逻辑；
2. 可行性实验（见 [16-实验记录与保真报告](16-实验记录与保真报告.md)）；
3. 外部现实核查（2026-08：Skills / MCP 生态现状）。

## 2. 被验证的主张链

```text
行为/日志 ─提取(INA-seq)→ 结构化决策模式 ─执行→ 决策
                              │
              ┌───────────────┼────────────────┐
         可移植/遗传       可进化           可交易(市场)
         (导出/导入)      (反馈→优化)      (验证→定价→分成)
              └──── 嫁接(融合) ────┘
              全部依赖：可信验证 (verification)
```

## 4. 两个核心洞察

### 洞察一：增量即弱点（INA 没有"已验证的差异化"）

- 与现状**重合**的部分（可执行、可移植、标准格式）→ 已被 Skills/MCP 验证 → INA 无差异化；
- **差异化**的部分（自动提取、进化、嫁接、交易市场）→ 全部无现实证据，且恰好是技术上最难、行业内也无人做成的环节；
- 推论：INA 要么沦为"Skills 的 DNA 叙事包装"，要么必须在自己最没证据的差异点上证明自己。

### 洞察二：验证是地基，而验证恰是全行业空白

- 可交易 → 需要可信验证；遗传 → 需要证明"换脑有效"；专家复制 → 需要证明提取保真；
- 但连 Anthropic 都没有发布 skills 的公开基准，现有效力证据全部是厂商自报；
- 推论：**"如何证明一个决策模式真的有效"是 INA 思路成立的第一性问题**，应先于一切其他环节。

## 5. 总体判定

**合理性**：

- 内部逻辑自洽，但与现状的锚点（skills/MCP/记忆协议）表明：INA 不是空想，有真实土壤；
- 但主张链过长，任一环节断掉，"认知 DNA"的故事就塌（链式论证的脆弱性）。

**有效性**：

- 底座主张（可执行、可移植）**已被行业验证有效** —— 这部分 INA 说得对，但也不是 INA 独有的；
- 差异化主张（自动提取、进化、嫁接、交易）**全部未验证**，其中自动提取与进化是最大未知；
- 交易市场主张**短期不成立**（验证问题 + 冷启动 + 安全）。

**一句话类比**：

> Skills 生态已经实现了"读取基因（识别/执行技能）"；
> INA 想做的"基因测序（自动提取）"、"基因编辑（进化/嫁接）"、"基因市场（交易）"——
> 后三者行业里都还没有人做成，而 INA 的整个商业模式恰好押在这三者上。

**结论**：INA 思路的**方向合理、叙事有锚点，但"差异化即未验证"**。它的价值不在于当下可落地，而在于指出了技能生态尚未覆盖的一条进化路径；它的风险在于把商业大厦建立在全行业都还没解决的"可信验证"之上。

## 7. 不开发前提下的判断

- 若目标是"做成可交易资产"：**当前不做** —— 验证问题未解决，市场无土壤；
- 若目标是"验证认知可否被编码、遗传"：**值得验证且成本低** —— 可在已有 skills 生态上做不写代码的对照（手写决策模式成 skill，真实 Agent A/B）；
- 最有信息增益的下一步验证（均非开发）：
  1. 提取保真实验（人肉 ground truth + 独立评判，消除偏置）——**已执行**，见 [16-实验记录与保真报告](16-实验记录与保真报告.md) 实验二；
  2. skills 生态对照（INA 决策模式 vs 无 INA，在真实 Agent 上）——未执行，可纳入 [12-研发路线图与阶段门禁](../05-工程与商业/12-研发路线图与阶段门禁.md) 或 [14-首个验证实验方案](14-首个验证实验方案.md) 的后续迭代。

## 8. 遗留开放判断

本卷判定后仍未决的问题（与 [13-风险登记与开放问题](../03-治理与演化/13-风险登记与开放问题.md) 第 6 节交叉引用）：

1. 自动提取（INA-seq）是否可能——逆问题，无成熟先例，唯一先例为本项目合成数据提取（偏置未消除）；
2. 进化（evolve）的反馈信号与奖励函数如何定义；
3. 嫁接的语义冲突检测如何规模化；
4. 可信验证体系由谁建立（行业空白，涉及第三方基准、盲评协议与计分标准）；
5. 全量盲评（评判者不知各方身份）作为保真评估的下一步可选验证。

在以上任一问题获得证据前，对应的差异化主张一律维持"待验证"状态。
