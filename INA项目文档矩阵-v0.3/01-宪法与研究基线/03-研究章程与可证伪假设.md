# 研究章程与可证伪假设

## 1. 研究决策

本阶段研究需要支持的决策是：

> INA 是否值得作为一种独立的 Cognitive Adaptation IR 继续投入，以及首个可验证实现应采用什么最小表示和执行后端。

## 2. 核心问题

> Agent experience 中是否存在稳定、可识别的 cognitive adaptation；这种 adaptation 能否被编码为模型无关的中间表示，并在一种或多种执行后端中再现其行为效应，同时保留显式表示的编辑、迁移、组合、审计和演化价值？

## 3. 主假设

### H1：可提取性

相似任务轨迹中存在跨案例稳定的认知变化，而不只是语言风格或事后总结。

### H2：可表示性

认知变化可以被表示为包含语义策略、行为示范、偏好关系、激活范围和评价契约的独立 Artifact。

### H3：可执行性

同一 INA 经过 Prompt、Runtime 或 Training Backend 后，能在未见任务上稳定改变 Agent 行为。

### H4：表示增益

相比直接 Prompt 或直接 Fine-tuning，INA 至少在可编辑性、数据效率、跨模型迁移、审计、组合或演化中提供一项显著价值。

### H5：可进化性

在正确归因和回归保护下，INA 能从新经验中改善，而不发生不可控漂移。

## 4. 强反方假设

### H0-A：不存在稳定 cognition

所谓模式只是提取器对少量轨迹的过度解释。

### H0-B：INA 只是更复杂的 Prompt

去掉 JSON 和术语后，效果完全由自然语言指令解释。

### H0-C：直接训练更优

`trajectory → fine-tune` 始终比 `trajectory → INA → fine-tune` 更简单、效果相同，且 INA 没有带来额外治理价值。

### H0-D：认知无法稳定组合

不同 INA 在真实上下文中冲突严重，Graft 无法超过独立加载。

### H0-E：显式化得不偿失

解释、编辑和谱系带来的收益低于复杂度、延迟与性能损失。

## 5. 研究范围

首阶段限定为：

- 文本和工具调用型 Agent；
- 可观测输入、检索、工具行为、结构化理由摘要、输出和结果；
- 软件工程决策中的窄任务族；
- 人工编写或半自动提取的 Symbolic INA；
- Prompt 与 Runtime 作为第一批执行后端；
- SFT、DPO 和 LoRA 作为后续强基线与编译目标。

首阶段不依赖模型私有思维链。

## 6. 证据要求

每个核心 Claim 必须记录：

- Claim 内容；
- 当前状态；
- 所需证据；
- 首选来源；
- 反方解释；
- 置信度；
- 修正触发器；
- 对应实验。

## 7. 初始 Claim Register

| 编号 | Claim | 状态 | 关键证据 | 否定信号 |
|---|---|---|---|---|
| C-01 | 轨迹中存在稳定认知适应 | 待验证 | 多任务一致性与专家盲评 | 提取结果不稳定 |
| C-02 | Symbolic INA 可独立表示 cognition | 待验证 | 跨 Backend 语义保持 | 必须为每个模型重写 |
| C-03 | INA 能改变未见任务行为 | 待验证 | 隐藏集增益 | 只在示范案例有效 |
| C-04 | INA 提供 Prompt 之外的价值 | 待验证 | 编辑、迁移、审计等对照 | 仅等价于长 Prompt |
| C-05 | INA 可被编译进训练流程 | 待验证 | SFT/DPO 编译保真度 | 直接训练全面更优 |
| C-06 | 认识论宪法降低谄媚 | 待验证 | Stance Sensitivity 测试 | 变成机械反对 |
| C-07 | 认知进化可控 | 待验证 | Replay 与回归结果 | 漂移超过收益 |
| C-08 | INA 是可交易认知资产 | 商业假设 | 真实购买、复用和收益 | 用户只愿购买普通内容 |
| C-09 | 企业端侧 Agent 需要 INA | 商业假设 | 私有部署试点 | 普通策略配置已足够 |

## 8. 研究纪律

- 初始假设与结论分开保存；
- 负面结果不得隐藏；
- 使用最强合理基线；
- 重要任务预先冻结指标和隐藏集；
- 结论必须写适用范围和反证条件；
- 任何“复制专家智能”的表述都必须降级为可测行为主张；
- 市场需求不能由技术可行性推导，必须独立验证。
