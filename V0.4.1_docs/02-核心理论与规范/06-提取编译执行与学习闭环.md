# Adaptation Learner 与学习闭环

## 1. 完整闭环

```text
Experience / Feedback / Outcomes
        ↓
Adaptation Learners
        ↓
Candidate Behavioral Delta
        ↓
INA Validation
        ↓
Accept / Reject
        ↓
Cognitive State update
        ↓
Realization
        ↓
Agent Behavior
        ↓
Effect Extraction
        ↓
Conformance Check
        ↓
Feedback to Learner
```

## 2. Adaptation Learner

任何能够提出 candidate Δ 的机制都属于外部/上游 Learner：

| Learner 类型 | 说明 | 状态 |
|---|---|---|
| Human authoring | 人工编写 Adaptation Contract | 当前主要方式 |
| Memory consolidation | 从长期记忆中归纳行为模式 | 待验证 |
| SkillOpt-like learner | 自动优化 Skill | 已有外部工作 |
| Bayesian evolution | 贝叶斯在线更新 | 已有外部工作 |
| Harness evolution | Harness 配置自适应 | 已有外部工作 |
| RL | 强化学习 | 成熟方法 |
| Fine-tuning | 微调内化 | 成熟方法 |
| Trajectory miner | 从轨迹中挖掘模式 | 待验证 |
| LLM reflection | LLM 自我反思提取 | 待验证 |

**INA 不需要重新发明它们。**

INA-seq 重新定义为：

> 一种候选 Adaptation Learner，而不是 INA 项目必须自己垄断的学习方法。

禁止把：

```text
trajectory → Skill summary
```

当核心壁垒。

## 3. INA Validation

Candidate Δ 必须通过 INA Validation 才能被接受：

```text
Candidate Δ
    ↓
Adaptation Contract 检查
    ↓
Evaluation Contract 检查
    ↓
Semantic Invariants 检查
    ↓
Forbidden Regressions 检查
    ↓
Cross-Harness Fidelity 检查（如适用）
    ↓
Accept / Reject / Revise
```

## 4. Realization

同一个 Δ 可以有多种 realization：

### Prompt Backend

把 Δ 转换为适合当前模型的系统提示。

优势：低成本、快速验证、易编辑。
风险：Context 占用、执行不稳定、容易退化为普通 Prompt。

### Skill Backend

把 Δ 编译为 Agent Skill。

优势：标准化、可复用、跨客户端。
风险：缺乏 behavioral verification。

### Runtime Backend

由路由器和策略执行器按情境激活。

优势：可控、可审计、可组合。
风险：工程复杂、延迟和模型遵循度。

### SFT Backend

由 Demonstration 生成监督训练数据。

优势：可内化稳定行为。
风险：数据质量、过拟合和更新成本。

### DPO Backend

由 Preference Pair 生成 chosen/rejected 数据。

优势：适合表达难以形式化的行为偏好。
风险：偏好数据可能过于表面，丢失作用域。

### LoRA / Adapter Backend

把稳定、高频 delta 编译为参数增量。

优势：推理效率高、可部署到端侧。
风险：可解释性下降、组合和回滚需要额外管理。

## 5. 关键数据契约

每次执行至少记录：

- `request_id`
- 激活的 Δ 与版本
- 激活理由和置信度
- 实际使用的 realization
- 发生的冲突和解决结果
- 输出或行动
- 评价
- 是否进入进化候选

这些日志既是评测资产，也是后续 Adaptation Learner 的输入。

## 6. 热认知与稳定认知

建议分层：

```text
Runtime Delta
  适合快速变化、个人化和近期经验

Compiled / Neural Delta
  适合长期稳定、高频和低延迟
```

稳定 delta 可以逐步下沉到 Training Backend；快速变化继续留在 Symbolic/Runtime 层。
