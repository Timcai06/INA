# 风险登记与开放问题

## 1. 核心风险（v0.4 新增）

### R1 — Skill Equivalence

Native Skill 已足够，INA IR 没有额外价值。

后果：项目失去存在理由。

缓解：Phase 2 Skill Equivalence Test 作为最高优先级 Kill Gate。

### R2 — Harness Absorption

未来 Harness 直接吸收所有 adaptation 能力。

后果：INA Control Plane 被边缘化。

缓解：关注 Harness 无法提供的 verified behavioral adaptation 能力。

### R3 — Eval Commoditization

LangSmith / Braintrust / Phoenix / Letta Evals 等普通 Eval 产品覆盖我们的产品形态。

后果：第一产品失去差异化。

缓解：聚焦 Cross-Harness Fidelity 和 Behavioral Conformance，这是普通 Eval 不覆盖的。

### R4 — Semantic Non-portability

同一 Δ 在不同 Harness 上无法保持意义。

后果：Cross-Harness Fidelity 失败，INA 核心主张不成立。

缓解：Phase 1 双 Harness 测试尽早验证。

### R5 — Manifest Decorative Risk

IR 字段无法产生可预测行为变化，只是漂亮 metadata。

后果：Adaptation Contract 变成装饰品。

缓解：Mutation Test 必须证明 contract 字段与行为变化的因果关系。

### R6 — Model Upgrade Fragility

模型升级后所有 policy 都需人工重写。

后果：维护成本过高。

缓解：关注 stable delta，接受部分 policy 需要更新。

### R7 — Giant Native Adoption

Anthropic / OpenAI / xAI 原生加入类似 behavioral policy regression。

后果：INA 被原生功能替代。

缓解：关注 cross-vendor 的 verified adaptation，这是单一厂商难以提供的。

### R8 — Marketplace Prematurity

没有 conformance metric 时 Cognitive Asset 无法定价。

后果：Marketplace 无法运作。

缓解：Marketplace 降级为远期，先做 Conformance。

### R9 — Overclaiming MCP Analogy

MCP 类比仅为 Partial Analogy，不可当核心论证。

后果：过度类比导致错误方向。

缓解：MCP 只是参考，不是支撑。

## 2. 概念风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| Behavioral Delta 定义无限扩张 | 项目不可测 | 限定可观察行为与作用域 |
| 把世界观做成意识形态 | 工程和伦理失控 | 拆成认识论、方法论、偏好 |
| 把风格当行为 | 虚假迁移 | 评价决策和行动，不评价语气 |

## 3. 科学风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| 提取器事后解释 | 虚假规则 | 重复提取、隐藏集、反例 |
| 数据泄漏 | 夸大效果 | 冻结测试集和来源隔离 |
| 裁判模型偏好 | 评价失真 | 人工盲评、多裁判 |
| 只和弱基线比较 | 无法证明价值 | Native Skill、Prompt、Training 强基线 |
| 反谄媚变成反对癖 | 能力下降 | 同时测准确率和反对率 |

## 4. 工程风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| Schema 过重 | 无法采用 | 最小必填与扩展字段 |
| 所有 Delta 全量注入 | Context 污染 | Scope 与激活阈值 |
| Runtime 绑定单模型 | 无法迁移 | 模型适配层 |
| Realization 丢失语义 | 不可信 | Realization Fidelity |
| 演化回归 | 历史能力丢失 | Replay、Regression、Rollback |

## 5. 治理风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| 原始对话被当商品 | 隐私与法律问题 | 只交易脱敏 Adaptation Contract |
| 来源不清 | 无法授权 | Provenance 与许可必填 |
| 低质量 Delta 传播 | 谱系污染 | 验证等级和撤销 |
| 企业行为泄露 | 商业秘密风险 | 私有 Registry 和端侧部署 |
| 核心宪法被用户修改 | 安全与可靠性下降 | 分层权限和高门槛变更 |

## 6. 商业风险

| 风险 | 后果 | 缓解 |
|---|---|---|
| 用户只需要 Prompt | 无付费理由 | 证明迁移、编辑、审计增益 |
| 免费额度太少 | 用户未体验价值 | 覆盖最小成长闭环 |
| 市场先于资产标准 | 劣币驱逐良币 | 先做 Schema、验证和许可 |
| 企业普通策略系统已足够 | INA 无差异化 | 用 Cross-Harness 和长期演化验证 |

## 7. 关键开放问题

1. Behavioral Delta 的最小单元是什么？
2. 何种行为稳定性才算 delta？
3. Adaptation Contract 与高质量 Prompt 的最低差异是什么？
4. 如何量化 Cognitive Distance？
5. 如何进行跨 Harness 语义对齐？
6. Router 的输入和训练方式是什么？
7. 核心宪法是否允许个性化？
8. 如何分配失败责任？
9. Neural Delta 如何回译或审计？
10. 认知资产的著作权、商业秘密和衍生权如何界定？
11. 免费层需要多少次 Agent 调用才能达到首次价值？
12. 企业端侧是否愿意接受 Compiled Delta 的更新和撤销机制？
13. 当核心假设失败时，项目应收缩成 Runtime Policy、Dataset Compiler 还是 Evaluation Infrastructure？

## 8. 项目级 Kill Criteria

以下任一结论被多轮实验稳定支持时，应重新评估 INA 主线：

- Native Skill + Eval 完全等价（H0-Skill 成立）；
- 同一 Delta 在不同 Harness 上方向不一致；
- 与 Prompt 无法区分；
- 直接训练在效果和治理上都全面优于 INA；
- 显式化得不偿失；
- 认知资产没有复用和付费价值。
