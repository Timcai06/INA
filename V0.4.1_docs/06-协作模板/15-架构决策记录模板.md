## 使用原则

- 重大概念、Schema、评测和商业计量变化都应写 ADR；
- ADR 记录当时为什么这样决定，不因后来结果不佳而篡改；
- 新决定通过"替代"旧 ADR，而不是删除历史；
- 每个 ADR 必须有修正触发器和 Kill Criterion；
- "因为感觉更先进"不能作为充分理由；
- 必须回答 Why Not Native Skill / Memory / Harness Patch。
