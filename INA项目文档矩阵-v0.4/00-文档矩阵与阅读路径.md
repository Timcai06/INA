# INA 文档矩阵与阅读路径

## 1. 这套文档解决什么问题

本目录是 INA 项目从 v0.3 升级到 v0.4 的文档基线。v0.4 的主题是 **Verified Behavioral Adaptation**。

当前文档聚焦五件事：

1. 把 INA 从 "Cognitive Adaptation IR" 重新定义为 **Verified Behavioral Adaptation Control Plane**；
2. 把 Behavioral Delta 确立为一等对象，Cognitive State 重新定义为逻辑状态；
3. 建立以 Behavioral Conformance 为核心的评测与验证体系；
4. 明确 Phase-0 Kill Experiment 的生死标准；
5. 保留长期商业方向，但将 Marketplace / Graft / 自动 Evolution 降级为远期。

**产品楔子不再暂缓。** 完整 PRD 仍然暂缓。

## 2. v0.4 核心转变

| 维度 | v0.3 | v0.4 |
|---|---|---|
| 一等对象 | Cognitive State | Behavioral Delta |
| 核心定义 | Cognitive Adaptation IR | Verified Behavioral Adaptation Control Plane |
| 与 Harness 的关系 | 另一个 runtime | Control plane on top of harness |
| 学习方法 | INA-seq 为核心 | Adaptation Learner 外部化 |
| 第一产品 | 未明确 | Behavioral Conformance |
| 验证重点 | 认知能否被表示 | adaptation contract 是否有独立价值 |

## 8. 当前项目主基调

> INA 是一个 Verified Behavioral Adaptation Control Plane。它不负责规定 Agent 必须通过什么机制学习。它负责定义、验证、迁移、治理和回滚 Agent 究竟学会了什么行为/判断变化。

核心公式：

```text
Base Agent + Behavioral Adaptation Δ = Adapted Agent
```

最终核心句：

> **INA makes agent adaptation explicit, testable, portable, and governable.**

## 9. 七条统一原则

1. INA 不发明 Agent 如何学习。INA 定义、验证和治理 Agent 学会了什么。
2. Cognitive State 是逻辑状态，不是必须独立存在的物理存储。
3. Skill / Memory / Hook / Prompt / Rule / Steering / Weight 都只是 realization。
4. INA 的语义由 behavioral effect + evaluation contract 定义。
5. 跨 Harness 的目标是 baseline-relative effect semantic equivalence，不是输出相同。
6. INA 必须允许实验杀死自己。
7. 当前项目阶段是 Research + Phase-0 Engineering，不是 Marketplace / Enterprise Platform / Cognitive OS。

## 10. 本阶段明确不做

- 完整产品 PRD；
- UI、设计系统和页面原型；
- 大规模 Marketplace；
- 无人工门禁的自动 Evolution；
- 声称 INA 已成为下一代 Agent 标准；
- 在 Kill Experiments 完成前构建重型商业平台。
