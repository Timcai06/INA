# Phase-0 Kill Experiment

## 1. 实验结构

本实验分为三个连续阶段，按顺序执行：

```text
Experiment 14-A: Delta Causality（单 Harness）
        ↓
Experiment 14-B: Skill Equivalence（单 Harness，最高优先级 Kill Gate）
        ↓ 只有 H0-Skill 未成立
Experiment 14-C: Cross-Harness Fidelity（双 Harness）
```

只有前一阶段通过门禁后，才允许进入下一阶段。

## 2. Baseline Fingerprint 要求

每次实验 run 前必须冻结并采集 Fingerprint：

```yaml
baseline_fingerprint:
  id: "<fingerprint-id>"
  harness:
    name: "<harness-name>"
    version: "<harness-version>"
  model:
    provider: "<provider>"
    name: "<model-name>"
    version: "<model-version>"
  system:
    prompt_hash: "<sha256:...>"
    instruction_files: ["<files>"]
    instruction_hashes: ["<sha256:...>"]
  tools:
    enabled: ["<tools>"]
  permissions:
    profile: "<profile>"
  skills:
    enabled: ["<skills>"]
  memory:
    mode: "<mode>"
  runtime:
    temperature: <value>
  environment:
    workspace_revision: "<rev>"
  uncontrolled_variables: []
```

要求：

- 每次 run 前采集 Fingerprint；
- 每次 run 后再次确认没有 drift；
- Baseline 与 Adapted 两侧 Fingerprint 必须一致；
- Realization 自身不得进入 Baseline Fingerprint；
- Realization 单独记录 hash；
- Fingerprint 变化时，该 run 不得进入正式统计。

交付物中增加：

```text
Baseline Fingerprint Snapshot
Fingerprint Diff Report
Uncontrolled Variables Register
```

## 5. Experiment 14-A: Delta Causality

### 目标

证明 Adaptation Contract 字段与行为变化之间存在可测、方向可预测的关系。

### 条件

只使用 **一个 Harness** 和一个 Baseline Fingerprint。

- **A：Baseline（Vanilla Agent）** — 无额外行为要求
- **B：Native Skill** — 使用与 Delta 等量的自然语言原则编写的 Agent Skill
- **C：INA Realization** — Delta 通过单一 Harness 的 realization
- **E：Sham Delta** — 结构一致但原则错误或随机
- **F：Wrong-domain Delta** — 加载不相关领域 delta

### 测试类型

- Add Test：delta 产生可测量的行为变化
- Removal Test：移除 delta 后行为回退
- Mutation Test：修改 contract 字段导致可预测行为变化
- Against-Prior：delta 真正改变 Agent 的 prior
- Scope Test：delta 不过度影响 out-of-scope 任务
- Regression Test：task success / general capability 不可接受退化

### 门禁

- Add Test 通过；
- Removal Test 通过；
- Against-Prior 通过；
- Sham / Wrong-domain 明显更差。

### 交付

```text
1 个 Baseline Fingerprint
1 个 Adaptation Contract
1 个 Harness Realization
Paired Replay
Effect Vector
Add / Removal / Mutation / Against-Prior 结果
Baseline Fingerprint Snapshot
Fingerprint Diff Report
```

此阶段不要求：

- 两个 Harness Adapter；
- Cross-Harness Fidelity；
- Cross-Harness Threshold。

## 6. Experiment 14-B: Skill Equivalence（最高优先级 Kill Gate）

### 目标

强制判断：INA vs Native Skill + ordinary Eval。

### 条件

仍然使用 **同一个 Harness** 和同一个 Baseline Fingerprint。

比较：

```text
Native Skill + Ordinary Eval
vs
INA Adaptation Contract + Realization + Conformance
```

必须控制：

- 自然语言信息量；
- token 长度；
- 示例数量；
- 工具权限；
- 模型版本；
- Harness 版本；
- 评测任务；
- Baseline Fingerprint。

### 评价维度

评价的不只是准确率，还包括：

- Causal Attribution；
- Editability；
- Auditability；
- Rollback；
- Scope Control；
- Mutation Predictability；
- Maintenance Cost。

### 门禁（Kill Criterion）

> 如果 Native Skill + ordinary Eval 在效果、迁移、维护、审计和复杂度上全部等价或更优，则停止或 Pivot INA IR 主张。

这是项目最高优先级 Kill Gate。**H0-Skill 未成立后才允许进入 14-C。**

### 交付

```text
Native Skill Baseline
Skill Equivalence Report
复杂度与治理对比
继续 / Pivot / Stop ADR
```

## 7. Experiment 14-C: Cross-Harness Fidelity

### 前置条件

只有 14-B 没有杀死 INA 才执行。

### 目标

证明 same Δ → different realization → same-direction effect。

### 条件

此时才引入：

```text
Harness Candidate A
Harness Candidate B
```

两个 Harness 的最终选择必须引用 Harness Selection ADR（见 [12-研发路线图](../05-工程与商业/12-研发路线图与阶段门禁.md) 第 13 节）。

### 测试

```text
Direction(Effect_CandidateA(Δ | F_A)) ≈ Direction(Effect_CandidateB(Δ | F_B))
```

其中 `F_A` 和 `F_B` 是各自 Harness 下具体 Agent 的 Baseline Fingerprint。

不同 Harness 拥有不同 Baseline，因此跨 Harness 比较不是绝对行为相同，而是方向一致。

方向一致；核心行为变化一致；作用域一致。

### 交付

```text
2 个 Harness Adapter
Cross-Harness Effect Vector
Fidelity Report
```

## 10. Kill Criteria

### 支持 INA 继续

- 14-A：Add / Removal / Against-Prior 通过；
- 14-B：INA 在至少一项治理维度上优于 Native Skill；
- 14-C：两个 Harness 上方向一致。

### 削弱 INA

- 14-B：System Prompt / Native Skill 完全解释全部增益；
- delta 只增加篇幅和延迟；
- 用户立场变化仍显著操纵结论；
- 正确和错误 delta 无差异；
- 14-C：两个 Harness 上方向不一致。

### 项目停止

- Native Skill + Eval 完全等价（H0-Skill 成立）；
- Cross-Harness Fidelity < 0.5（provisional threshold，正式实验前冻结）：

```yaml
threshold:
  metric: "cross_harness_fidelity"
  operator: "<"
  value: 0.5
  status: "provisional"
  source: "engineering_hypothesis"
  rationale: "Phase-0 initial gate"
  frozen_at: null
```

- 多轮实验稳定支持以上任一削弱条件。
