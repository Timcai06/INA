# 前沿研究与范式转向记录（Competitive Research Ledger）

## 1. 目的

本卷不是普通论文综述。

它记录 INA 从 v0.3 Pivot 到 v0.4 的**外部压力来源**：哪些已有工作证明了什么，哪些 INA 旧主张被杀死，哪些问题仍然开放，以及 INA 因此做出什么回应。

每项竞争工作统一采用 Competitive Research Ledger 格式处理。首先把它们作为 **competition / kill evidence** 处理，而不是 INA 的支持材料。

## 2. 覆盖类别

| 类别 | 核心问题 |
|---|---|
| Skill Evolution | Agent Skill 能否自动进化？ |
| Procedural Memory | 过程性知识如何被持久化？ |
| Harness Evolution | Agent Harness 本身能否自适应？ |
| Persistent Agent State | Agent 状态能否跨会话持久化？ |
| Agent Skills | Skills 生态的当前形态与边界 |
| Cross-Harness Transfer | 同一适应能否跨 Harness 迁移？ |
| Agent Eval / Regression | Agent 评测方法的当前水平 |

## 3. Competitive Research Ledger

### 3.1 SkillOpt

| 维度 | 内容 |
|---|---|
| **Work** | SkillOpt |
| **Date / Version** | 2025 |
| **Primary Source** | 论文/项目 |
| **Exact Capability** | Agent Skill 可以通过优化流程自动改进，不需要人工逐条编写 |
| **Overlap with INA** | 自动 Skill 生成 |

## 4. 范式转向总结

### 4.1 被杀死的 INA v0.3 主张

| 旧主张 | 杀死原因 | 状态 |
|---|---|---|
| 自动提取 Skill 是核心壁垒 | SkillOpt 等工作已经在做 | ❌ 放弃 |
| INA 是唯一能保存判断方式的方案 | ProcMEM、Letta 等可以保存 procedural knowledge | ❌ 放弃 |
| INA Runtime 是核心执行层 | Harness 已经内建 adaptation 机制 | ❌ 降级 |
| INA 是新的 Skill 层 | Agent Skills 已成为事实标准 | ❌ 放弃 |
| 市场是核心路线 | 验证问题未解决时市场无意义 | ⏸️ 远期 |
| 自动进化/Graft 是近期目标 | 技术不成熟，行业无先例 | ⏸️ 远期 |

### 4.2 仍然开放的问题

| 问题 | 当前状态 | INA v0.4 回应 |
|---|---|---|
| Skills 是否需要 behavioral verification | 行业空白 | INA 的核心价值主张 |
| 同一 adaptation 能否跨 Harness 保持语义 | 未验证 | 核心研究问题 (H-Core) |
| Native Skill + Eval 是否足够 | 未验证 | 核心 Kill Gate (H0-Skill) |
| Harness 是否会吸收所有 adaptation 能力 | 可能 | 风险 R2，需要实验验证 |

### 4.3 INA v0.4 的新定位

```text
Original INA:
Independent Cognitive State Layer
→ PIVOT

INA v0.4:
Verified Behavioral Adaptation Control Plane
→ GO TO KILL EXPERIMENTS
```

核心转变：

| 维度 | v0.3 | v0.4 |
|---|---|---|
| 一等对象 | Cognitive State | Behavioral Delta |
| 核心主张 | 独立认知层 | Verified adaptation control |
| 与 Harness 的关系 | 另一个 runtime | Control plane on top of harness |
| 与 Skills 的关系 | 新的 skill 层 | Verification layer for skills |
| 学习方法 | INA-seq 为核心 | Adaptation Learner 外部化 |
| 市场定位 | Marketplace 是核心 | Conformance 是第一产品 |
| 验证重点 | 认知能否被表示 | adaptation contract 是否有独立价值 |
