# 谱系与回滚

## 1. 稳定核心与可进化外围

Delta 的成长不是全部字段同时变化。

建议分为：

```text
稳定核心
  认识论底线、证据诚实、修正能力

领域方法
  可通过领域实验逐步优化

个体偏好
  可随用户长期交互快速变化
```

不同层使用不同的变更门槛。

## 2. 版本与谱系（Control Plane 必须有）

### 版本管理

每个 Adaptation Contract 必须有版本号：

```text
major.minor.patch
```

- major：语义不兼容变更
- minor：向后兼容的功能新增
- patch：向后兼容的缺陷修复

### 谱系记录

谱系记录的不只是版本号，而是：

- 父版本；
- 继承了什么；
- 修改了什么；
- 删除了什么；
- 为什么变化；
- 哪些证据支持；
- 在什么 Benchmark 上更好或更差；
- 是否允许继续派生。

示例：

```text
架构决策 Δ v1
├── 创业团队变体 v1
│   └── 端侧应用变体 v2
└── 金融合规变体 v1
```

## 3. 回滚（Control Plane 必须有）

### 回滚条件

以下情况应触发回滚：

- 行为回归超过阈值；
- 发现语义不变量被违反；
- Cross-Harness Fidelity 下降；
- 新证据否定当前 delta。

### 回滚流程

```text
检测到问题
    ↓
定位回滚目标版本
    ↓
验证回滚目标的有效性
    ↓
执行回滚
    ↓
回归测试
    ↓
通知相关方
```

## 4. Cognitive Credit Assignment

一次任务的结果必须在多个因素间归因：

- 基础模型；
- Delta；
- 检索；
- 工具；
- 上下文；
- 执行环境；
- 随机性；
- 未知。

只有 Delta 责任达到证据阈值，才允许修改 Adaptation Contract。

## 5. Replay 与回归保护

每个成熟 Delta 必须维护：

- 历史成功样例；
- 已知失败样例；
- 边界条件；
- 认识论宪法测试；
- 关键用户场景；
- 冲突测试。

候选版本需要满足：

```text
新任务表现提升
历史能力无显著下降
核心宪法保持
已知失败不扩大
```

## 6. Cognitive Distance

用于衡量两个版本之间的行为变化程度。

可以包含：

- 规则新增与删除；
- 优先级改变；
- Preference Reversal；
- 作用域变化；
- 宪法变化；
- 示例分布变化。

大幅变化必须提升审查等级。

## 7. 远期能力（Post-Validation / Long-term）

以下能力在 v0.4 中明确标记为远期：

### Automatic Evolution

自动从经验中进化 Delta。

当前状态：行业无成熟先例，技术不成熟。

### Graft（嫁接）

把多个 Delta 在目标领域中进行冲突解析和协同合成。

当前状态：冲突检测需真实语义理解，规模化极难。

### Marketplace

认知资产的交易市场。

当前状态：验证问题未解决时市场无意义。

### Complex Cognitive Inheritance

复杂的认知继承和派生。

当前状态：需要成熟的谱系和验证体系。

## 8. 交易与衍生权（远期）

谱系是可交易性的基础。

每个可派生 Delta 应记录：

- 原作者；
- 当前维护者；
- 许可；
- 是否允许修改；
- 是否允许商业使用；
- 衍生收益规则；
- 撤销和安全更新传播方式。

具体分成比例属于未来市场规则，不在本阶段冻结。
