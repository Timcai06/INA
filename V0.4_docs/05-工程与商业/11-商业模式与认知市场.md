# 商业模式与产品楔子

## 1. 文档定位

本文件定义第一产品（Behavioral Conformance）和长期商业原则。

所有商业判断当前都属于待验证假设。

## 2. 第一产品：Behavioral Conformance

### User

同时使用 2 个及以上 Coding Agent，并维护团队级 Agent 行为/工程原则的 AI-native software team。

### Pain

他们的问题不是"没有 Memory"，而是：

> 我们不知道团队要求的 Agent 行为在不同模型 / Harness / 版本中是否真的生效。

### Product

核心命令：

```bash
ina test <policy>
```

### MVP

包含：

- Behavioral Delta Manifest；
- 2–4 Harness Adapters；
- Baseline / Adapted Paired Replay；
- Effect Vector Evaluation；
- Against-Prior；
- Regression；
- Cross-Harness Fidelity；
- CI Report。

不包含：

- Dashboard；
- Marketplace；
- Auto-learning；
- Memory SaaS；
- Consumer App。

详细内容见 [17-Behavioral Conformance 产品楔子](../04-评测与实验/17-Behavioral Conformance产品楔子.md)。

## 3. 免费额度

首阶段免费额度统一按照 Agent 调用次数计算。

### 计费单位

一次 Agent 调用：

> 外部 Agent 为完成一个顶层任务，向 INA 服务发起一次认知请求并收到有效响应。

### 免费层目标

免费额度必须足够让开发者经历至少一个最小价值闭环：

```text
接入
→ 多次 Agent 调用
→ 形成或加载 Delta
→ 感受到可见的判断变化
→ 再决定是否付费
```

## 4. 收费层次

### Developer Cloud

- 免费 Agent 调用额度；
- 超额后按调用次数计费。

### Team

- 团队 Delta 共享；
- 权限、版本和审核；
- 调用额度池；
- 私有 Registry。

### Enterprise / Edge

- 私有化部署；
- 本地 Control Plane；
- 审计、撤销、策略治理；
- Air-gapped 场景；
- 定制支持与授权。

### Personal / To C

远期提供个人 Delta：

- 跨 Harness 迁移；
- 长期行为成长；
- 私人行为资产管理。

## 5. 可交易性（远期）

可交易性必须保留为长期属性。

市场交易的不是聊天记录，而是经过脱敏和验证的：

- Adaptation Contract；
- Domain Methodology；
- Epistemic Policy；
- Team Template；
- Compiled Delta 许可。

## 6. 市场可信度（远期）

一个可交易 Delta 至少展示：

- 作者和所有权；
- 来源与脱敏声明；
- 许可；
- 适用范围；
- 版本和谱系；
- 兼容 Harness；
- Benchmark 与证据等级；
- Kill Criteria；
- 已知失败；
- 撤销状态。

## 7. 商业顺序

1. 先让开发者免费体验真实价值（Behavioral Conformance）；
2. 再验证按 Agent 调用收费；
3. 再验证 Team 与 Enterprise 私有治理；
4. 在资产标准和验证机制成熟后开放 Market；
5. To C Personal Delta 作为长期扩展。

不能先建交易所，再证明认知资产是否存在。
